ระบบเฝ้าระวังและวิเคราะห์การระบาดของโรคติดเชื้อไวรัสโคโรนา 2019 (COVID-19)

พัฒนาสำหรับนักวิชาการสาธารณสุขและเจ้าหน้าที่ผู้ปฏิบัติงานควบคุมโรค | ออกแบบรองรับไฟล์มาตรฐาน DDC Excel / CSV

ขั้นตอนการนำไฟล์นี้ขึ้น GitHub Pages

เพื่อเปิดใช้งานเป็นเว็บไซต์ให้ทีมงานเข้าถึงได้จากทุกอุปกรณ์

1
บันทึกโค้ดนี้เป็นไฟล์ index.html

คัดลอกโค้ด HTML ทั้งหมดในหน้านี้ แล้วเซฟชื่อไฟล์ว่า index.html ลงในคอมพิวเตอร์ของคุณ

2
สร้าง Repository บน GitHub

เข้าเว็บ GitHub.com คลิกปุ่ม New Repository ตั้งชื่อตามต้องการ (เช่น covid19-dashboard) และเลือกตั้งค่าเป็น Public

3
อัปโหลดไฟล์ index.html

คลิก Upload an existing file แล้วลากไฟล์ index.html ขึ้นไป จากนั้นกดปุ่ม Commit changes

4
เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings > Pages ของ Repository นั้น
ตรงหัวข้อ Build and deployment (Branch) ให้เลือกเป็น main หรือ master แล้วกด Save

เสร็จสิ้น! รอประมาณ 1-2 นาที คุณจะได้ลิงก์ URL เช่น https://username.github.io/covid19-dashboard ที่สามารถแชร์ให้เพื่อนร่วมงานเปิดดูผ่านมือถือหรือคอมพิวเตอร์ได้ทันที!
